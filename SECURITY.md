# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is a high priority for BREAQ. If you discover a security vulnerability or sensitive information exposure:

1. **Do not create a public issue** on GitHub.
2. Please privately report the vulnerability via GitHub Security Advisories or contact the maintainers directly.
3. Provide a detailed summary of the vulnerability, including:
   - Type of vulnerability.
   - Exact steps or proof-of-concept to reproduce.
   - Affected components or files.
   - Potential impact.

We will acknowledge receipt of your report within 48 hours and work diligently to validate, patch, and release a fix.
